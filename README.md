# Regn & Rug – demonettside for bakeri i Bergen

Statisk demoside (HTML, CSS, JS) laget for å vise frem nettsidedesign for småbedrifter.
Bakeriet, adressen og kontaktinfoen er oppdiktet.

- Live: https://regn-og-rug-bakeri.vercel.app
- Foto: Unsplash (Unsplash-lisens), lenket direkte fra images.unsplash.com
- Kart: OpenStreetMap
- Fonter: Fraunces og Inter (Google Fonts)

Ingen byggesteg: åpne `index.html` i nettleseren, eller deploy mappen som den er.
